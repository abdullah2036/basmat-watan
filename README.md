# بصمتي لوطني — جمعية فتاة الخليج
### مركز الطفولة المبكرة · روضة الأطفال النموذجية
#### اليوم الوطني السعودي ٩٦ — مبادرة مديرة الروضة ملاك المهاجري

موقع تفاعلي بالعربية يسير مع الطفل خطوة بخطوة:

**اسمك ← بصمتك على الخريطة ← مشاركتك ← الجدار**

| الخطوة | ماذا يحدث |
|---|---|
| **البداية** | الطفل يكتب اسمه ويضغط «ابدأ» فينتقل الموقع للنشاط |
| **١ · بصمة وطن** | يضغط بإصبعه على اللوحة، فتنطبع بصمته على خريطة المملكة باسمه — مع صوت وقصاصات احتفالية، والعدّاد يزيد |
| **٢ · مشاركتك** | رؤيته لوطن مزدهر، أو عبارة، أو رسالة صوتية، أو صورة |
| **٣ · الجدار** | كل المشاركات تظهر **مباشرة** بلا مراجعة ولا انتظار، ويتحدّث الجدار تلقائيًا كل ٦ ثوانٍ |

البصمات والمشاركات **تتراكم ولا تُحذف**.

---

## ١) التشغيل السريع (بدون أي إعداد)

افتحي `index.html` في المتصفح. كل شيء يعمل فورًا — لكن البيانات تُحفظ في الجهاز المفتوح عليه فقط. مناسب للتجربة والعرض.

---

## ٢) وضع المشاركة الحقيقي — ليراها كل الأهالي

لتتراكم البصمات من كل الأجهزة في مكان واحد. الخطة المجانية من Supabase تكفي. **الوقت: ١٠ دقائق.**

1. سجّلي في <https://supabase.com> → **New project** (اختاري منطقة قريبة، مثلًا Frankfurt).
2. **SQL Editor → New query** → الصقي محتوى `supabase/schema.sql` كاملًا → **Run**.
3. **Project Settings → API** → انسخي `Project URL` و `anon public` key.
4. الصقيهما في `assets/js/config.js`:

   ```js
   supabaseUrl:     "https://xxxxxxxx.supabase.co",
   supabaseAnonKey: "eyJhbGciOi...",
   ```

انتهى. لا حساب ولا كلمة مرور ولا لوحة إدارة — الموقع يعمل مباشرة.

> `anon public key` مصمَّم ليكون داخل صفحة الموقع؛ هذا طبيعي. **لا تضعي مفتاح `service_role` أبدًا.**

**لو احتجتِ حذف مشاركة غير مناسبة:** Supabase → Table Editor → `entries` → حدّدي الصف → Delete. نفس الشيء لجدول `prints`.

---

## ٣) النشر على الإنترنت

اسحبي مجلد المشروع كاملًا إلى <https://app.netlify.com/drop> — رابط جاهز خلال ثوانٍ. أو Vercel أو GitHub Pages؛ الموقع ملفات ثابتة ولا يحتاج خادمًا.

التسجيل الصوتي يتطلب رابط **https** — كل الخيارات أعلاه توفّره.

## ٤) الصور والشعارات

### الحالة الآن

| الملف | الحالة |
|---|---|
| `logo-kindergarten.png` | ✅ الشعار الرسمي — مُكبّر ومحسّن (٩٦٠×٩٦٠) |
| `logo-moe.png` | ✅ شعار وزارة التعليم الرسمي — العلامة المائية محذوفة، مُكبّر (١١٦٤×٩٠٦) |
| `school.jpg` | ✅ صورة المبنى الأصلية — مُكبّرة ومحسّنة (١٣٨٠×١٠٣٥) |
| `logo-nationalday.png` | ⬜ **ناقص** — يُعرض رسم مؤقت بدلًا منه |

الناقص الوحيد: هوية **عزّنا بطبعنا** الرسمية. حمّليها من الهوية الرسمية لليوم الوطني، وسمّيها `logo-nationalday.png`، وضعيها في `assets/img/`. تظهر فورًا بعد تحديث الصفحة (Ctrl + F5).

### تحسين أي صورة لاحقًا

```bash
pip install pillow
python tools/enhance.py الأصلية.jpg assets/img/school.jpg --width 1600
python tools/enhance.py شعار.png assets/img/logo-nationalday.png --logo
```

الأداة تكبّر بخوارزمية LANCZOS، تزيل التشويش، ثم تطبّق حدّة موجّهة. **لا تضيف ولا تحذف أي عنصر من الصورة.**

### آلية البديل

كل شعار في `index.html` يحمل `data-fallback`. لو لم يوجد الملف الرسمي يُعرض الرسم المؤقت تلقائيًا — فلا تنكسر الصفحة أبدًا.

### الخلفية المرسومة

مشهد الصحراء (`assets/img/scene.svg`) وشريط السدو (`sadu-strip.svg`) رسوم متجهة أصلية — حادّة عند أي حجم وبلا قيود ترخيص. لاستبدالها بحزمة رسومات مشتراة، غيّري سطرًا واحدًا في `assets/css/styles.css`:

```css
.scene{ background:url("../img/scene.png") center bottom / cover no-repeat; }
```

## ٥) التعديلات الشائعة

كلها في `assets/js/config.js`:

```js
kindergartenName: "روضة الأطفال النموذجية",
directorName:     "ملاك المهاجري",
nationalDayNumber:"٩٦",
nationalDayDate:  { year: 2026, month: 9, day: 23 },   // العدّ التنازلي
maxAudioSeconds:  60,
maxPhotoMB:       5,
maxTextChars:     280
```

الأسماء مكتوبة أيضًا في `index.html` (الترويسة والتذييل) — غيّريها هناك إن لزم.

**الصوت:** الموقع يولّد نغماته داخليًا (بلا ملفات صوت). الزائر يكتمه من الزر ♪ في الترويسة، ويُحفظ اختياره.

## ٦) قبل إرسال الرابط للأهالي

- **امسحي بيانات التجربة:** في SQL Editor نفّذي `truncate public.prints; truncate public.entries;`
- استبدلي الشعارات وصورة الروضة (القسم ٤).
- **المشاركات تُنشر مباشرة بلا مراجعة** — هذا ما طلبتِه ليفرح الأطفال بالنتيجة فورًا. يعني أيضًا أن أي شخص يملك الرابط يستطيع النشر. الرابط للأهالي فقط؛ ولو ظهر شيء غير مناسب احذفيه من Supabase خلال ثوانٍ (القسم ٢).
- يُستحسن إرسال رسالة للأهالي توضّح أن الصور ستُعرض على جدار المبادرة.

## ٨) الموسيقى الخلفية

زر الموسيقى في الترويسة منفصل عن زر المؤثرات الصوتية، ولكلٍّ منهما حالته المحفوظة.

**يعمل الآن** بلحن هادئ يولّده الموقع داخليًا — بلا أي ملف وبلا قيود ترخيص.

**لاستخدام نشيد وطني أو أغنية أطفال:** ضعي الملف في `assets/audio/` باسم `background.mp3`
(أو `.m4a` أو `.ogg`). الموقع يكتشفه تلقائيًا ويشغّله مكرّرًا بدل اللحن المولّد.

- يُفضّل أقل من ٣ ميجابايت
- الصوت مضبوط على ٢٢٪ حتى لا يغطّي المؤثرات
- **تأكدي من حقوق استخدام المقطع قبل النشر على الإنترنت**

المتصفحات تمنع تشغيل الصوت تلقائيًا عند فتح الصفحة، لذا تبدأ الموسيقى عند أول ضغطة من الزائر.

---

## ٩) تحديث الموقع بعد النشر

Netlify Drop **لا يُحدّث نفسه تلقائيًا**. بعد أي تعديل:

1. اسحبي مجلد `basmat-watan` كاملًا إلى صفحة الموقع في Netlify → تبويب **Deploys**
2. أو إلى <https://app.netlify.com/drop> من جديد

الرابط يبقى نفسه، والتحديث خلال ثوانٍ.

**البيانات لا تتأثر إطلاقًا.** البصمات والمشاركات محفوظة في Supabase وهي خدمة منفصلة —
إعادة نشر الموقع لا تمسّها.
